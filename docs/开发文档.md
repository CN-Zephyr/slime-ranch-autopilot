# 开发文档

《史莱姆牧场》一代的 NEKO 插件。默认观望，不操作游戏。按 V 进入自主经营：先到结晶市场，再收食物投喂、收结晶卖掉，钱够费用两倍才建造或升级。

仓库：<https://github.com/Yangmao-123/slime-ranch-autopilot>

## 两段程序

| 部分 | 位置 | 作用 |
| --- | --- | --- |
| NEKO 插件 | `__init__.py`、`ui/panel.tsx`、`plugin.toml` | 启动核心进程，把 `outbox.jsonl` 转成聊天消息，面板上切换模式 |
| 自动化核心 | `core/` | 观望 / 自主经营状态机，键鼠走路和吸附 |
| 游戏 mod | `bridge/SlimeBridge/` | 进游戏后在 `127.0.0.1:8124` 提供状态和动作 |

游戏目录里已经有 UnityCoreMod（和 `Mods\SRMP.dll` 同一套加载器）。`SlimeBridge.dll` 放到 `Mods\` 就会被加载，不需要再打成 `.umfmod`。

## 模式

- `watch`：观望。不按键、不走路、不主动说话。猫娘看不看画面，取决于玩家有没有开 NEKO 屏幕分享。
- `ranch`：自主经营。

V 键在两者之间切换。没装 `pynput` 时，Windows 用系统键盘钩子。切回观望会打断正在进行的走路。

自主经营一轮的顺序：

1. 人在主牧场就走到结晶市场。连续两次走不到，或不在主牧场，就传送到市场前。
2. 吸附近的食物。画面没有变化不算收进背包，也不会去围栏投。
3. 走到最近围栏，把背包里的东西投出去。
4. 吸附近结晶，再拿到市场投掷。卖完资金没有增加，不算卖出。
5. 资金达到下一档费用的两倍，才建造或升级。每种建筑只建一次，再加一个升级件。建造不会把人瞬移走。

不跑图，不抓野生史莱姆。

## 安装

在仓库根目录双击 `install.bat`，或执行：

```bat
py -3 install.py
```

脚本会：

1. 把仓库复制到旁边的 `N.E.K.O\plugin\plugins\slime_ranch_autopilot`（目录名必须是下划线）。
2. 在那份副本里建 `.venv-core`，安装 Pillow。
3. 把 `engine_python` 和找到的 `SlimeRancher.exe` 写入副本的 `plugin.toml`。
4. 用系统自带的 `csc.exe` 编译 `SlimeBridge.dll`，覆盖到游戏的 `Mods\SlimeBridge.dll`。

然后完全退出游戏再进存档。浏览器打开 `http://127.0.0.1:8124/api/health`，应返回 `{"ok":true,"name":"slime_bridge"}`。再重启 NEKO。

不装游戏时验收决策：

```bat
py -3 run_standalone.py --ticks 20 --interval 0 --backend sim
```

日志在 `data\runtime\outbox.jsonl`。`--ticks` 会临时切到自主经营。

## 配置

`plugin.toml` 的 `[slime_ranch]`：

| 键 | 含义 |
| --- | --- |
| `default_mode` | `watch` 或 `ranch`。旧值 `chat` 当成观望，`voice` 当成自主经营 |
| `game_exe` | 留空则在常见 Steam 目录里找一代游戏 |
| `engine_python` | 留空则用启动 NEKO 的 Python。要截图确认吸附时，指向 `.venv-core\Scripts\python.exe` |
| `backend` | `hybrid` 为桥接感知加真实键鼠。`sim` 不碰游戏 |
| `bridge_host` / `bridge_port` | 默认 `127.0.0.1:8124` |
| `auto_launch_game` | 桥接没起来时是否启动 `game_exe` |

两边用 `%TEMP%\neko-slime-ranch-autopilot\runtime` 交换文件：`config.json`、`command.json`、`state.json`、`outbox.jsonl`。

## 改自主经营时看哪里

- 循环：`core/main_controller.py` 的 `_ranch_tick`、`_reset_to_market`。
- 走路、吸附、投掷：`core/real.py`。吸附必须 `visual=True` 才算成功。
- 两倍资金和升级次数：`core/ranch.py`。`MAX_LEVEL = 2`，对应「建成」再加一个升级件。
- 游戏内扫描和传送：`bridge/SlimeBridge/GameState.cs`。
  - `scan_food`：60 米内的水果、蔬菜、鸡，围栏里正在被吃的不算。
  - `scan_plort`：40 米内的落地结晶，不追史莱姆。
  - `tp_market`：放到结晶市场站位点。
  - `build` / `upgrade`：扣钱并替换地块，不移动玩家。

改完 C# 后重新跑 `install.bat`，或只执行编译并覆盖 `Mods\SlimeBridge.dll`。游戏正在运行时覆盖会失败，先退出游戏。

## 桥接协议

`GET /api/health`  
`GET /api/status`  
`POST /api/action`，正文 `{"action":"...","kind":"..."}`。

自主经营会用到的 action：`scan_market`、`tp_market`、`scan_food`、`scan_plort`、`scan_corral`、`build`、`upgrade`、`set_overlay`。

## 验证

```bat
py -3 -m unittest discover -s tests
py -3 plugin_check.py
```

测试不要求仓库目录名等于插件 id。装进 NEKO 时目录必须是 `slime_ranch_autopilot`。
